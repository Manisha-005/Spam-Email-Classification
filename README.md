# Spam Email Classification Using Machine Learning

## 📌 Project Overview
This project aims to classify emails as **Spam or Not Spam** using Natural Language Processing (NLP) and Machine Learning techniques. It applies text preprocessing, TF-IDF feature extraction, and SMOTE to handle class imbalance.

## 🛠️ Technologies Used
- Python
- Pandas and NumPy
- NLTK
- Scikit-learn
- Imbalanced-learn
- XGBoost
- Matplotlib and Seaborn

## ⚙️ Methodology
1. Data Loading and Exploration
2. Text Preprocessing
3. Feature Extraction using TF-IDF
4. Class Balancing using SMOTE
5. Model Training
6. Model Evaluation and Comparison

## 🤖 Machine Learning Models
Five classifiers are implemented:

1. Logistic Regression
2. Multinomial Naive Bayes
3. Random Forest
4. XGBoost
5. Stacking Classifier (Logistic Regression as the final estimator)

## 📊 Evaluation Metrics
- Accuracy
- Precision
- Recall (Sensitivity)
- Specificity
- F1-Score
- Confusion Matrix

## 🚀 How to Run
1. Clone this repository.
2. Open the Jupyter Notebook in Google Colab.
3. Upload the `SpamAssasin.csv` dataset.
4. Install the required dependencies.
5. Run all cells to train and evaluate the models.
